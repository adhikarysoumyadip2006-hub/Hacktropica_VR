# 🎮 VR-Based Phobia Treatment System

## 📌 Overview
This project is a Virtual Reality (VR) based system developed using Unreal Engine to help users overcome common phobias through controlled exposure therapy.

## 🧠 Problem Statement
Phobias such as fear of darkness, heights, and confined spaces can significantly affect mental health. Traditional therapy methods may not always be accessible or engaging.

## 💡 Solution
We developed an immersive VR environment that simulates real-life scenarios to gradually expose users to their fears in a safe and controlled manner.

## 🎯 Features
- 🌑 Nyctophobia (Fear of Darkness) simulation using dark tunnels and lighting effects  
- 🏔️ Acrophobia (Fear of Heights) environment with elevated platforms  
- 🚪 Claustrophobia (Fear of Closed Spaces) using constricting tunnels  
- 🎮 Interactive VR controls using Meta Quest 2  
- 🔊 Realistic sound and visual effects for immersion  

## 🛠️ Technologies Used
- Unreal Engine  
- VR Hardware (Meta Quest 2)  
- Blueprint System (No heavy reliance on asset store)
